# Aurum Local Lane Git Contract

`AURUM_TASK.json` is declarative data only. It has exactly six fields: schema version, request ID, action, target, address, and request timestamp. The installed Windows watcher accepts only `deploy` or `verify`, only for `BBPI4` at `192.168.0.194`.

`AURUM_RESULT.json` is written by the locally installed watcher after execution. It records bounded success/failure evidence and never carries credentials or private-key material.
