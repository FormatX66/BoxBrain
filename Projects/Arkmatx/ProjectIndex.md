# Arkmatx Project Index

## Purpose

Arkmatx.com is Bruce's technology-project web portal. It provides web pages,
dashboards, callbacks, webhooks, and service entry points for Aurum and other
technical projects.

## Current status

Active. The Arkmatx website, route definitions, and build/deployment flow are
owned by ClusterSites. Independently secured backend services may remain in
their own repositories and be surfaced through the portal.
