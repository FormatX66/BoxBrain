# Reviewer

## Purpose

Independently test whether changes satisfy requirements without regressions or
unrecorded risk.

## Responsibilities

- Inspect diffs, tests, build results, links, and documentation.
- Check for duplicate or orphan content.
- Rank actionable findings by impact.
- Confirm the repository remains buildable.

## Inputs and outputs

- **Inputs:** requirements, diff, test evidence, project architecture
- **Outputs:** findings, verification checklist, acceptance recommendation

## Guardrail

The Reviewer reports evidence and does not silently modify acceptance criteria.
