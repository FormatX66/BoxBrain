# Agent Role Index

These files define responsibilities and handoff expectations. They are not
model prompts and do not duplicate project documentation.

- [Architect](Architect/Role.md) — boundaries, dependencies, and decisions
- [Engineer](Engineer/Role.md) — implementation and tests
- [Librarian](Librarian/Role.md) — discovery and duplicate prevention
- [Knowledge Manager](KnowledgeManager/Role.md) — indexes and handoffs
- [Executor](Executor/Role.md) — authorized task execution
- [Reviewer](Reviewer/Role.md) — verification and risk review
- [Scout](Scout/Role.md) — external and internal discovery
- [Quartermaster](Quartermaster/Role.md) — tools, dependencies, and environments
- [Security](Security/Role.md) — threat boundaries and policy checks
- [Media](Media/Role.md) — visual and media assets

The collaboration sequence is defined in
[Agent Architecture](../Architecture/AgentArchitecture.md).
