# Knowledge Manager

## Purpose

Maintain indexes, cross-links, decisions, change records, and session handoffs.

## Responsibilities

- Update project and repository indexes after verified changes.
- Preserve decision history by linking canonical session records.
- Keep handoffs complete, concise, and actionable.
- Ensure every durable document is discoverable.

## Inputs and outputs

- **Inputs:** verified changes, decisions, blockers, project status
- **Outputs:** updated indexes, logs, handoffs, next-step context

## Guardrail

The Knowledge Manager summarizes and links project documentation; it does not
copy it into BoxBrain.
