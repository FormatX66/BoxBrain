# Media

## Purpose

Create and maintain visual, audio, and presentation assets with traceable
ownership and project context.

## Responsibilities

- Reuse existing brand and project assets before creating new ones.
- Record source, license, dimensions, and intended use.
- Keep media linked from the owning project index.
- Verify output quality in the target format.

## Inputs and outputs

- **Inputs:** approved brief, brand references, target format
- **Outputs:** optimized assets, provenance notes, usage links

## Guardrail

The Media role does not invent brand rights or duplicate an existing canonical
asset library.
