# Templates

Use templates only to start a new canonical record; do not create a second
copy of an existing record.

## Project index fields

1. Purpose
2. Current status
3. Owner
4. Priority and completion estimate
5. Dependencies
6. Canonical documentation
7. Registered repositories
8. Related projects
9. Immediate next step

## Session bundle

Create a directory named `BB-YYYY-MM-DD-NNN` under
[SessionHandoffs](../SessionHandoffs/README.md) containing the nine files
defined by the canonical
[Repository Organization prompt](../PromptLibrary/RepositoryOrganization.md#required-session-bundle).

Session decision and change files are canonical for that session. Cumulative
Admin files index them rather than copying their full contents.
