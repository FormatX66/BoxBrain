# Questions

## Blocking before live Windows frames

- Which external credential provider will supply the low-privilege RDP session
  secret without copying it into the Pi database, Flutter storage, arguments,
  or audit records?
- What exact first-frame format should be canonical: bounded BGRA tiles,
  compressed PNG snapshots, or another deterministic fixture-first envelope?

## Non-blocking

- Should the enabled target be automatically disabled after each checkpoint
  restore until its certificate is independently reverified?
- Should a reviewed Pi API operator helper replace all ad hoc authenticated SSH
  commands?
- When recovery confidence is sufficient, should the detached answer ISO be
  securely removed through a separately approved cleanup task?
