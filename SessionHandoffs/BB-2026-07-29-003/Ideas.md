# Ideas

- Add a certificate-reverification command that reads guest and Pi observations
  in separate processes and emits only a boolean match plus evidence paths.
- Automatically disable a target whenever its clean checkpoint is restored,
  requiring a fresh identity probe before the next task.
- Provide a Pi-local operator utility that reads the API token through a file
  descriptor and never places it in output, arguments, environment, or shell
  tracing.
- Start the frame protocol with a deterministic color-bar fixture so size,
  cadence, redaction, and backpressure can be proven before a real desktop is
  visible.
- Keep evidence snapshots content-addressed and encrypted if persistence is
  later approved.
