# Ideas

- Make scrolling the next capability because it adds useful navigation with
  less data exposure than shell or clipboard.
- Add a no-change installer mode that reports all preflight and provenance
  gates without constructing deployment artifacts.
- Convert the Notepad click-and-type proof into a small deterministic lab app
  so coordinate and visual results do not depend on editor layout.
- Record wall time and peak resource use for nightshift jobs so future queues
  can be ordered by measured impact.
- Add optional nightshift automation only after its schedule, wake behavior,
  cleanup gates, and approval boundary are explicitly chosen.
