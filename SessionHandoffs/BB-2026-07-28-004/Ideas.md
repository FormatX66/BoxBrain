# Ideas

- Add a certificate-probe preview that shows bounded identity metadata before
  the operator decides whether to update a disabled target.
- Make approved target identities exportable as a signed, credential-free
  manifest for reproducible lab environments.
- Add time-limited enablement for temporary or rebuilt virtual machines.
- Require a second operator for fingerprint changes in high-assurance policy
  profiles.
- Add a migration test fixture for every released controller schema version.
- Use a fake FreeRDP executable in tests so process arguments and disabled
  capabilities are asserted without needing a live desktop.
