# Questions

## Open

- Which external credential provider should supply the dedicated RDP lab
  account after the observation plugin exists?
- Should the existing public BoxBrain remote remain public after the canonical
  organization is merged?
- Which project should be discovered and indexed after the target registry:
  Arkmatx, WebsiteBuilder, or AgentFramework?

## Resolved this session

- The first observation protocol is RDP through FreeRDP.
- Target identity uses an internal UUID plus an exact certificate fingerprint.
- Target approval is disabled by default and independently audited.
- Raw frames are memory-only and evidence retention is bounded.
- Both repository remotes are now known and configured locally.
